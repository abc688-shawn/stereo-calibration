# 双目相机测距工程

基于 Python + OpenCV 的双目立体视觉测距工具，支持两个独立 USB 摄像头。

## 快速开始

### 0. 安装依赖

```bash
pip install -r requirements.txt
```

> 需要 Python 3.7+ 和网络连接。

---

### 1. 修改配置（`config.py`）

接入相机后，打开 `config.py` 按实际情况修改：

| 参数 | 含义 | 常见值 |
|------|------|--------|
| `LEFT_CAM_ID` | 左摄像头设备索引 | `0` |
| `RIGHT_CAM_ID` | 右摄像头设备索引 | `1` |
| `FRAME_WIDTH` / `FRAME_HEIGHT` | 采集分辨率 | `1280, 720` |
| `CHESSBOARD_SIZE` | 棋盘格**内角点**数 `(列, 行)` | `(9, 6)` |
| `SQUARE_SIZE_MM` | 每个方格的实际边长（毫米） | `25.0` |

> **注意**：`CHESSBOARD_SIZE` 填的是**内角点**数量，即方格数 - 1。  
> 例如一张 10×7 方格的标定板，内角点应填 `(9, 6)`。

---

### 2. 采集标定图像

```bash
python 01_capture.py
```

**操作说明：**
- 窗口左侧为左相机，右侧为右相机
- 绿色边框 = 两侧都检出棋盘格；红色边框 = 未检出
- 按 **`s`** 保存当前帧（未检出时不保存，保证质量）
- 按 **`q`** 退出
- 加 `--force` 参数可强制保存未检出帧

**采集建议：**
- 建议采集 **15~25 对**图像
- 覆盖画面的不同区域（左/中/右、上/中/下）
- 变换标定板姿态（倾斜、旋转约 ±45°）
- 包含不同距离的图像
- 标定板必须在两个画面中都**完整可见**
- 移动后稍等一秒再按 `s`，避免运动模糊

图像保存在 `data/left/` 和 `data/right/`。

---

### 3. 双目标定

```bash
python 02_calibrate.py
```

脚本会自动：
1. 检测所有图像对中的棋盘格角点
2. 单目标定左/右相机内参
3. 双目联合标定，输出旋转 R、平移 T
4. 立体校正，生成视差-深度映射矩阵 Q
5. 保存参数到 `output/stereo_params.yml`
6. 生成校正验证图 `output/rectification_check.png`

**质量判断：**
| 指标 | 优秀 | 可接受 | 需重标 |
|------|------|--------|--------|
| 单目 RMS | < 0.3 px | < 0.8 px | > 1.0 px |
| 双目 RMS | < 0.5 px | < 1.0 px | > 1.5 px |

打开 `rectification_check.png`，检查：
- 左右图中棋盘格对应点应落在**同一水平绿线**上
- 若有明显垂直偏移，说明标定质量差，需重新采集

---

### 4. 实时测距

```bash
python 03_measure.py
```

**操作说明：**
| 操作 | 功能 |
|------|------|
| 鼠标左键点击左视图 | 查询该像素的距离（打印到终端并在画面标注） |
| 鼠标右键 | 清除所有距离标注 |
| `d` 键 | 开/关视差图窗口 |
| `r` 键 | 清除点击记录 |
| `q` 键 | 退出程序 |

输出示例：
```
  点 ( 640,  360)  |  Z(深度)=1.234 m   欧氏距离=1.251 m   [X=0.125m  Y=-0.045m  Z=1.234m]
```

- **Z(深度)**：被测点到相机平面的垂直距离
- **欧氏距离**：被测点到相机光心的空间直线距离

---

## 测距精度说明

- 测距单位与 `SQUARE_SIZE_MM` 一致（默认毫米→输出米）
- 最佳测距范围：**基线长度的 40~200 倍**（例如基线 6 cm，有效范围约 2.4 m ~ 12 m）
- 以下情况视差无效：纹理缺乏区域（白墙、玻璃）、遮挡边缘、高光区域

## 常见问题

**Q: 打开相机失败 / 只有一路正常**  
A: 检查 USB 连接；在终端运行 `python -c "import cv2; cap=cv2.VideoCapture(0); print(cap.isOpened())"` 确认索引。macOS 可能需要在「系统偏好 → 隐私 → 相机」授权终端/Python 访问。

**Q: 左右画面接反了**  
A: 在 `config.py` 里交换 `LEFT_CAM_ID` 和 `RIGHT_CAM_ID` 的值。

**Q: 棋盘格检测不到**  
A: 检查 `config.py` 中 `CHESSBOARD_SIZE` 是否与实物一致（填内角点数）；确保光照均匀、标定板完整在画面内。

**Q: 标定 RMS 误差很大（> 2 px）**  
A: 重新采集图像，注意：标定板需刚性（不能弯曲）、覆盖画面不同位置、避免模糊。

**Q: 测距时大量像素显示"无效"**  
A: 可能原因：SGBM 参数不适合当前场景；被测区域纹理太弱（尝试在物体上贴纸增加纹理）；可调整 `config.py` 中 `SGBM_NUM_DISPARITIES`、`SGBM_BLOCK_SIZE` 参数。

**Q: 测距结果偏差大**  
A: 确认 `SQUARE_SIZE_MM` 填的是实际测量值（用游标卡尺量）；重新采集更多高质量图像重新标定。

## 工程结构

```
Calibration/
├── requirements.txt      # 依赖列表
├── config.py             # 全部参数配置（接相机后改这里）
├── utils.py              # 公共工具函数
├── 01_capture.py         # 图像采集
├── 02_calibrate.py       # 双目标定
├── 03_measure.py         # 实时测距
├── data/
│   ├── left/             # 左相机标定图
│   └── right/            # 右相机标定图
└── output/
    ├── stereo_params.yml         # 标定参数
    └── rectification_check.png  # 校正验证图
```
